# 🔌 skf-socket

> **WebSocket для SkyForge:** сервер и клиент с русскоязычными функциями.

**Автор:** `SkyMonder` · **Лицензия:** MIT

---

## 📦 Установка

Пакет использует библиотеку [`websockets`](https://pypi.org/project/websockets/) из PyPI.

**Шаг 1.** Установи зависимость:

```bash
pip install websockets
```

**Шаг 2.** Установи сам пакет через SkyForge:

```bash
SkyForge install skf-socket --trust
```

---

## 🚀 Использование

### 🖥️ Сервер

```skyforge
подключить("skf-socket")

пусть сервер = создать_сервер(8080)

при_подключении(сервер, функция(ws) {
    лог("Привет, новый клиент!")
})

при_сообщении(сервер, функция(сообщение) {
    вернуть "Сервер получил: " + сообщение
})

запустить_сервер(сервер)
```

### 💻 Клиент

```skyforge
подключить("skf-socket")

пусть клиент = создать_клиент("ws://localhost:8080")

подключиться(клиент)
отправить(клиент, "Привет, сервер!")

пусть ответ = получить(клиент)
лог("Ответ: " + ответ)

закрыть(клиент)
```
